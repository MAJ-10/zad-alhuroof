رفع دفعة أسئلة

الصق من إكسل أو جداول جوجل مباشرة، أو ارفع ملف CSV. عمودان (السؤال ثم الإجابة) ويُستنتج الحرف من أول الإجابة، أو ثلاثة أعمدة يكون أولها الحرف.

تفعيل الحفظ

اكتب اسمك والصق المفتاح الذي أرسله لك مسؤول الموقع. يُحفظان في هذا المتصفح وحده ولا تحتاج إعادتهما. واسمك يُوقَّع به كل تعديل تحفظه.
لمسؤول الموقع: كيف أنشئ مفتاحاً لمشرف؟
  1. افتح صفحة إنشاء مفتاح دقيق من حسابك.
  2. Token name: اسم المشرف، لتعرف أيّ مفتاح تلغي لاحقاً.
  3. Repository access ← Only select repositories ← … وحده.
  4. Permissions → Repository permissions → Contents = Read and write. لا تعطِه شيئاً غيرها.
  5. Generate token، ثم أرسل الناتج للمشرف ليلصقه هنا مرة واحدة.

أنشئ مفتاحاً مستقلاً لكل مشرف، فتلغي مفتاح واحد دون أن تعطّل البقية. والإلغاء من نفس الصفحة في أي وقت.
